# go-mc26-lang

The languages of Minecraft: Java Edition that [go-mc26](https://github.com/mj41/go-mc26) does not carry (it
has English built in), one Go module per language, generated by [mc26](https://github.com/mj41/mc26).

| branch or tag | what |
|---|---|
| `mc-<version>` | the languages of a Minecraft version: a directory and module per language (`cs-cz/`, module `github.com/mj41/go-mc26-lang/cs-cz`) |
| `<lang>/v0.<YYN>.<n>` | a language's module at a version (`cs-cz/v0.263.0`): a new tag only when its file changed |
| `blobs` | every language file of every version by its checksum, what go-mc26's langget fetches |

See go-mc26's package lang for using them.
